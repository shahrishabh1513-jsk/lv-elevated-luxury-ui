# ✨ LV Elevated Luxury UI

A premium, cinematic luxury fashion website UI inspired by **Louis Vuitton** 🖤 — built with HTML, CSS and JavaScript.  
Experience a high-end digital design with video hero sections, refined animations, and responsive layouts.

👉 Live Demo: https://shahrishabh1513-jsk.github.io/lv-elevated-luxury-ui/

---

## 🌟 Features

🎥 **Cinematic Hero Grid** – immersive full-screen video background  
📱 **Responsive Design** – scales smoothly from large screens to mobile  
✨ **Elegant Animations** – smooth hover effects & transitions  
🖋 **Luxury Aesthetic** – refined typography, spacing and layout  
🧠 **Smart Navigation** – transparent → solid navbar on scroll

---

## 🛠️ Built With

✅ HTML5  
✅ CSS3 (Flexbox + Grid + Media Queries)  
✅ JavaScript (DOM Manipulation & Scroll Logic)  
✅ Google Fonts (Inter, Playfair Display)  
✅ Optional Font Awesome Icons

---

## 📐 Design Highlights

- **Hero Section:** Cinematic video + grid layout  
- **Navigation:** Auto hides on scroll down, reappears on scroll up  
- **Services:** Animated cards with hover scale  
- **Footer:** Responsive accordion system for mobile  
- **Typography:** Elegant luxury pairing
