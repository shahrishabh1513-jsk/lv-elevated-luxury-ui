## 📖 About The Project

**LV Elevated Luxury UI** is a front-end recreation of a high-end luxury fashion brand's website, built purely as a **UI/UX design and front-end engineering exercise**. The goal was to study and reproduce the visual language of premium editorial-style e-commerce — full-bleed video hero sections, minimalist navigation, generous whitespace, and refined typography.

It focuses entirely on presentation and interaction design: cinematic autoplay video banners, a "Services & Savoir-Faire" section, and a detailed mega-footer — with **no backend, no real products, and no checkout**.

> 💬 *"Maison Fondée en 1854 — Savoir-Faire, Voyage, Artisanat Français."*

## 🚀 Getting Started

### Option 1 — Use the live version

No setup needed 👉 **[Open the live build](https://shahrishabh1513-jsk.github.io/lv-elevated-luxury-ui/)**

### Option 2 — Run it locally

```bash
# 1️⃣ Clone the repository
git clone https://github.com/shahrishabh1513-jsk/lv-elevated-luxury-ui.git

# 2️⃣ Navigate into the project directory
cd lv-elevated-luxury-ui

# 3️⃣ Open index.html in your browser
#    (or use the Live Server extension in VS Code)
```

✅ No build tools, dependencies, or installations required — it's a pure **HTML/CSS/JS** project.
